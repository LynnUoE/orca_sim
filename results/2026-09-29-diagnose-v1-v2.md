# 2026-09-29 v1 与 v2 最佳模型的失败诊断（45°）

模型：v2 run20（目标旋转向量 + 指尖观测，seed 0），v1 run23（同样设置，seed 1）。
命令：`python -m orca_rl.diagnose --model runs/<run>/final_model.zip --goal-angle 45 --episodes 60`，每回合 400 步。

| | v2 run20 | v1 run23 |
|---|---|---|
| 进入目标锥（15°）的目标比例 | 65% | **38%** |
| 进入后保持满 10 步的比例（转化率） | 70% | 61% |
| 失败的保持：方块仍在转（过冲） | 78% | 78% |
| 失败的保持：失去接触 / 掉到掌下 | 15% | 13% |
| 失败的保持：慢慢漂出 | 7% | 9% |
| 离开目标锥时的方块角速度（中位 / p90） | 2.77 / 6.37 rad/s | 3.00 / 10.63 rad/s |
| 方块在手中的时间 | 91% | 95% |
| 掉落结束的回合 | 0 / 60 | 2 / 60 |

## 结论

1. **v1 主要差在「转不到位」，不在「握不住」。** 进入目标锥的比例 38% 对 65%，转化率只差 9 个百分点。
   与 `2026-09-27-run22-24-v1.md` 的观察一致：v1 场景里指尖离方块 13–16 cm（v2 为 7–8 cm）。
   下一步需要实物的方块尺寸、质量、摆放位置和手的姿态，把 v1 场景对齐后重训。
2. **两只手的主要失败方式相同：过冲。** 保持失败的 78% 是方块还在以约 3 rad/s 转动时冲出了目标锥。
   之前在奖励上试过的刹车项（run9 的 `spin_penalty`、`align_bonus`）和前瞻势函数（run11、run13）都没有超过基线的两个 seed（见 `2026-09-24-run11-13.md`），需要换思路。
3. 诊断脚本的判断对两者都是「到达与保持大致各半，瓶颈在样本量」；目前每个 run 只有 3000 万步。
